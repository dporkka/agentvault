Use Postgres for primary storage

Decision platform accepted

Context

We need a durable store that supports structured relational queries, JSONB for flexible metadata, and vector search via pgvector.

Decision

Use Postgres as the primary database. SQLite remains the local vault index and can be rebuilt from Markdown at any time.

Consequences

  • Single operational datastore simplifies backups.
  • pgvector extension enables semantic search without a separate service.
  • Requires Postgres 15+ in production.
